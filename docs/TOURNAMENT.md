## Method (what was actually run)

Everything below was run by the tournament worker on 2026-11-07 between 19:51 and ~20:06 CT (the brief said 18:12 CT, but the
wall clock was 19:47 CT when the worker started, so the compute budget was much smaller than planned). One process at a time,
`nice -n 19`, `timeout 200`, each run capped by `--max-seconds` (35-80 s, see table titles), no worker pools. The chain scripts are
`sim-out/tournament/run_all.sh` and `run_extra.sh`; raw output is `sim-out/tournament/*.txt|json`; tables are generated by
`sim-out/tournament/aggregate.py` into `sim-out/tournament/tables.md`. Rack size 5 everywhere, `src/sim/run.ts` harness, fixed seeds
4101-4116, Vickrey except the FirstPrice run. In every non-self run each strategy plays the same bags, the same seat and the same
opponents (duplicate matches / common random numbers), so differences between strategies inside one run are paired.

| tournament stage | what was simulated | runs |
|---|---|---|
| Swiss (6 and 7 players) | each candidate and topbot-like as the tested seat vs fitted models: 6p = topbot-like x2, mid-bot x2, quick-cycler; 7p adds hoarder | A1, A2 (Vickrey), A3 (FirstPrice) |
| Swiss SELF | mcvalue, tuned, economist, topbot-like, mid-bot, quick-cycler in one 6-seat table, seats rotated | A4 |
| Bracket 4p / 3p | candidates vs topbot-like + mid-bot + quick-cycler (4p), vs topbot-like + mid-bot (3p); and candidates vs each other | B1, B2, B3, B4 |
| Final heads-up | each candidate vs topbot-like (C4-C6 paired; C0, C0b unpaired cross-check), and each candidate pair head to head (C1-C3) | C0, C0b, C1, C2, C3 |
| Sanity | lobby-sims and starters fields, 6p Vickrey, the three candidates | S1, S2 |
| Stress (not in the weights) | each candidate vs five topbot-like (hardest fitted field) | A5 |

"Swiss pts" = players - place (ties share), as in the server. Swiss/bracket scores are normalised to the fraction of the maximum,
(N - place)/(N - 1), so 6p, 7p, 4p, 3p runs can be averaged. Final = P(win a 3-game series decided on TOTAL score), estimated as
Phi(sqrt(3) * mu / sd) where mu and sd are the mean and standard deviation of the per-game score difference (candidate minus opponent).
For candidate vs candidate the SD comes from the paired per-match differences (exact). For candidate vs topbot-like the opponent's
score is a separate row, so the SD assumes zero correlation between the two seats; shared bags usually make that correlation
positive, so this SD is probably too big and the probabilities are pulled toward 50% (conservative). The normal approximation is
inferred, not checked against a simulated 3-game series.
Composite = 0.40 Swiss-Vickrey (A1 40%, A2 40%, A4 20%) + 0.20 bracket (B1-B4 equal) + 0.25 final (mean over opponents) + 0.15
Swiss-FirstPrice (A3). "Points-equivalent" = composite x 5 (a 6-player Swiss table awards 0-5 points, 2.5 is the table average).
Composite SEs are unpaired and therefore conservative for gaps between candidates (they share bags inside a run).

1. Swiss tables are 6-7 players and decide the top cut: economist has the best sim Swiss record but only 8 live matches, below its sim level. tuned and mcvalue have almost no live record.
   Do not choose on sim alone: more live matches for mcvalue and tuned would settle it.

3. FirstPrice is a guess for all three (no real FirstPrice history). economist's +23.1 +-2.3 points over mcvalue there (n=81) is probably inflated because the fitted models bid as in Vickrey.

## Limitations

- n per run: A1 115, A2 128, A3 81, A4 74, B1 34, B2 24, B3 27, B4 17, A5 54, C0 37, C0b 31, C1 53, C2 18, C3 25, C5 41, C6 21, C4 400, S1 7, S2 8 (SEs on each row).
- Bracket = 4p and 3p tables, mean finishing fraction; no last-place-out elimination bookkeeping and no separate 6p/5p elimination tables.
- 3-game series probability is a normal approximation of the total-score difference using the paired per-game SD (inferred, not simulated as 3 games).
- C0 and C0b (candidates vs topbot-like, unpaired) are kept as cross-checks: win% tuned 70.3 / 77.4, mcvalue 56.8 / 61.3, economist 27.0 / 32.3. They agree with the paired runs.
- lobby-sims and starters sanity runs: all three candidates won 100% of 7-8 matches each.
- topbot-like words() reached 496 ms in the self runs; it is an opponent model, not a submission. Baselines were not rerun. Nothing was run against the live server.
- Opponent models do not react to our bids; the real field does.
